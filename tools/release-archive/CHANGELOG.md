# Changelog

## 1.0.0 - 2026-08-23

- Initial `dut-tools` release.
- ZIP and TAR.GZ output from one deterministic file-selection plan.
- Git tracked-file selection with optional untracked files.
- Clean-tree enforcement and Git-base awareness.
- TOML include/exclude configuration.
- Dry-run and CI `--check` modes.
- SHA-256 release manifest and checksum sidecar.
- Reproducible archive ordering, timestamps and normalized metadata.
